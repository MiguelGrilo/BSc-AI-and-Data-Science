# 0. Eventastic ‐ Especificação do Sistema (Backend)

## Eventastic

Este projeto consiste na especificação da primeira parte do trabalho prático, focada no backend de um sistema de gestão de eventos, denominado **Eventastic**. <br>
O objetivo do Eventastic é apoiar todo o processo de organização, inscrição e participação em atividades como conferências ou workshops. 
A documentação completa do projeto, gerenciada nesta Wiki do GitHub, está organizada nas seguintes secções obrigatórias, conforme exigido pela especificação:
